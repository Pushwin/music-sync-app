> **Perfect music synchronization across multiple devices**

Listen to music together with friends, no matter where you are. Harmony Sync ensures everyone hears the same song at the exact same time with zero delay.

## ✨ Features

- 🎯 **Perfect Sync** - Sub-50ms precision across all devices
- 🎵 **YouTube Integration** - Search and play millions of songs
- 📁 **File Upload** - Add your own music files
- 👑 **Smart Control** - One admin controls playback for everyone
- 📱 **Mobile Friendly** - Works on any device with a browser
- ⚡ **Real-time** - Instant synchronization using WebSocket technology

## 🚀 Quick Start

1. **Visit** [Live Demo](https://music-sync-app-3o1w.onrender.com)
2. **Share** the link with friends
3. **Play** music and enjoy perfect sync!

## 🎮 How It Works

- **First person** becomes the DJ (admin)
- **Others join** by opening the same link
- **Everyone hears** the same music in perfect harmony
- **Drag timeline** to jump to any part of the song on all devices
